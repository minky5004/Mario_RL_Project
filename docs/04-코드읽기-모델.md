## 0. "모델"이란?

여기서 **모델(model)** 은 머신러닝 모델이 아니라, **데이터를 담는 그릇(클래스)** 을 뜻합니다.
[02장](02-전체구조와통신.md)에서 본 두 종류의 JSON —

- Java → Python 으로 보내는 **행동** → `Action`
- Python → Java 로 받는 **상태** → `GameState`

이 두 JSON을 Java 객체로 다루기 위한 클래스입니다.

---

## 1. `Action` — 행동 6가지 (enum)

파일: `src/main/java/com/mario/rl/model/Action.java`

```java
public enum Action {
    NOOP(0),           // 아무것도 안 함
    RIGHT(1),          // 오른쪽 이동
    RIGHT_JUMP(2),     // 오른쪽 + 점프 (가장 중요)
    JUMP(3),           // 제자리 점프
    LEFT(4),           // 왼쪽 이동
    RIGHT_RUN_JUMP(5); // 오른쪽 달리기 + 점프

    public static final int ACTION_SIZE = 6;
    private final int value;

    Action(int value) { this.value = value; }
    public int getValue() { return value; }
    ...
}
```

### 왜 `enum`인가?
- 행동은 **딱 6가지로 고정**되어 있습니다. 이런 "정해진 목록"은 `enum`이 제격입니다.
- 그냥 `int 2` 대신 `Action.RIGHT_JUMP` 라고 쓰면 코드가 **읽기 쉬워지고 실수도 줄어듭니다.**

### `value`가 따로 있는 이유
- Java 안에서는 `RIGHT_JUMP`라는 **이름**으로 쓰지만,
- Python에게는 숫자 `2`로 보내야 합니다 (`{"action": 2}`).
- 그래서 각 행동에 **번호(`value`)** 를 붙여두고, 보낼 때 `getValue()`로 꺼냅니다.

```
Java 내부:  Action.RIGHT_JUMP   ←(이름으로 안전하게)
보낼 때:    getValue() → 2      →  {"action": 2}  → Python
```

### `ACTION_SIZE = 6`
- Q-Table의 **열(column) 개수**가 됩니다 ([01장](01-강화학습이란.md)의 `double[1000][6]`의 `6`).
- 숫자 `6`을 코드 곳곳에 흩뿌리지 않고 **상수 하나로** 모아둔 것(매직넘버 방지).

### `fromValue(int)` — 반대 방향 변환
```java
public static Action fromValue(int value) {
    for (Action action : values()) {
        if (action.value == value) return action;
    }
    throw new IllegalArgumentException("정의되지 않은 액션 인덱스: " + value);
}
```
- 숫자 → 행동으로 되돌리는 헬퍼. 잘못된 숫자가 오면 **예외를 던져** 버그를 빨리 잡습니다.

## 2. `GameState` — 게임 상태 그릇

파일: `src/main/java/com/mario/rl/model/GameState.java`

```java
public class GameState {
    private int mario_x;       // 마리오 X 좌표
    private int mario_y;       // 마리오 Y 좌표
    private boolean enemy_near;// 근처 적 존재
    private int score;         // 점수
    private int time_left;     // 남은 시간
    private double reward;      // 이번 보상
    private boolean done;       // 한 판 끝났나
    private String info;        // 종료 원인
    // ... getter / setter ...
}
```

### 필드 이름이 왜 `mario_x` (snake_case) 인가?
보통 Java는 `marioX`(camelCase)를 씁니다. 그런데 여기선 **일부러 `mario_x`** 로 썼습니다.

이유: **Python이 보내는 JSON 키와 글자가 똑같아야** 자동 변환(Gson)이 됩니다.

```json
{ "mario_x": 320, ... }     ← Python이 보낸 JSON 키
         │  (이름이 같아야)
         ▼
  private int mario_x;       ← Java 필드
```

> 💡 이름이 다르면(`marioX`) Gson이 짝을 못 찾아 값이 `0`으로 들어옵니다.
> (나중에 `@SerializedName` 애너테이션으로 camelCase를 쓸 수도 있지만, 지금은 단순하게 맞췄습니다.)

### getter/setter
- 필드는 `private`(외부에서 직접 못 건드림)로 숨기고, `getMarioX()` 같은 **통로**로만 접근합니다.
- `Gson`이 JSON → 객체로 바꿀 때 이 setter들(또는 필드)을 사용합니다.

### `toString()`
- 디버깅용. `System.out.println(state)` 하면 상태가 한 줄로 예쁘게 찍힙니다.

## 3. 이 두 클래스가 전체에서 차지하는 위치

[02장](02-전체구조와통신.md)의 흐름과 연결하면:

```
Python ──(JSON 상태)──▶  [GameState]  ──▶ StateEncoder ──▶ QLearning
                                                              │
Python ◀──(JSON 행동)──  [Action]    ◀───────────────────────┘
```

- `GameState` = **입력** (받는 것)
- `Action` = **출력** (보내는 것)
- 둘 다 **데이터만 담는 단순한 그릇** — 로직은 없습니다. (로직은 뒤 장의 클래스들이 담당)
