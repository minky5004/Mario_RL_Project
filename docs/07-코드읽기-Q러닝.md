## 1. 이 클래스가 가진 것 (필드)

파일: `src/main/java/com/mario/rl/agent/QLearning.java`

```java
private final double[][] qTable;   // 점수표 [상태][행동]
private final Random random;       // 동전 던지기 (탐험용)
private double epsilon;            // 탐험 비율 (1.0 → 0.01)
```

생성자에서 표를 **0으로 가득 채워** 시작합니다. (아직 아무것도 모르는 상태)

```java
public QLearning() {
    this.qTable = new double[STATE_SIZE][ACTION_SIZE];  // [1000][6], 전부 0.0
    this.random = new Random();
    this.epsilon = INITIAL_EPSILON;                      // 1.0
}
```

### 학습 파라미터 (상수)
```java
LEARNING_RATE   = 0.1;    // α 새 정보 반영 비율
DISCOUNT_FACTOR = 0.99;   // γ 미래 보상 중시도
INITIAL_EPSILON = 1.0;    // 처음엔 100% 탐험
EPSILON_DECAY   = 0.995;  // 매 판 0.995배씩 줄임
EPSILON_MIN     = 0.01;   // 최소 1%는 탐험 유지
```
이 5개 숫자가 학습의 "성격"을 정합니다. ([01장](01-강화학습이란.md) 복습)

## 2. 행동 고르기: `selectAction` (epsilon-greedy)

```java
public int selectAction(int state) {
    if (random.nextDouble() < epsilon) {   // ① 동전 던지기
        return random.nextInt(ACTION_SIZE); // ② 탐험: 아무거나
    }
    return argMax(qTable[state]);           // ③ 활용: 표에서 최고점
}
```

### 한 줄씩
- **①** `random.nextDouble()`은 0~1 사이 난수. 이게 `epsilon`보다 작으면 → 탐험.
  - epsilon=1.0(초반)이면 거의 항상 참 → **거의 항상 무작위**.
  - epsilon=0.01(후반)이면 거의 항상 거짓 → **거의 항상 최선**.
- **②** 탐험: `0~5` 중 아무 행동이나. "안 해본 것도 시도"해서 표를 채웁니다.
- **③** 활용: `argMax`로 **현재 상태 행에서 Q값이 가장 큰 행동**을 고름.

```
       epsilon = 0.8 일 때
   ┌──────────────────────────┐
   │  80% 무작위 탐험           │
   │  20% 표에서 최고 행동 활용  │
   └──────────────────────────┘
```

### `argMax` 보조 메서드
```java
private int argMax(double[] values) {
    int bestIndex = 0;
    double bestValue = values[0];
    for (int i = 1; i < values.length; i++) {
        if (values[i] > bestValue) { bestValue = values[i]; bestIndex = i; }
    }
    return bestIndex;
}
```
- 6개 행동의 Q값 중 **가장 큰 값의 위치(인덱스)** 를 찾습니다.
- "가장 좋은 행동이 몇 번이냐?"에 답하는 함수.

## 3. 배우기: `update` (벨만 방정식의 코드판) ⭐⭐

이 메서드가 **학습 그 자체**입니다.

```java
public void update(int state, int action, double reward, int nextState, boolean done) {
    double target = done
            ? reward                                          // ① 끝났으면 보상만
            : reward + DISCOUNT_FACTOR * maxValue(qTable[nextState]); // ② 아니면 미래까지
    qTable[state][action] += LEARNING_RATE * (target - qTable[state][action]); // ③ 갱신
}
```

### ① target — "이 행동의 진짜 가치는 얼마였나?"
- **에피소드가 끝났으면(`done`)**: 미래가 없으니 `target = reward` (받은 보상이 전부).
- **안 끝났으면**: `target = reward + γ·(다음 상태의 최고 Q값)`
  - = "지금 받은 보상 + 앞으로 잘하면 받을 미래 보상의 기대치"
  - `maxValue(qTable[nextState])` = 다음 상태에서 낼 수 있는 최선의 점수.

```
target = 지금 보상(reward) + 0.99 × 다음 상태에서의 최선
                              └ γ(미래를 0.99배로 살짝 할인)
```

> 💡 `done`을 구분하는 이유: 죽은 다음 상태의 Q값을 더하면 **존재하지 않는 미래**를 끌어오는
> 셈이라 학습이 망가집니다. 그래서 끝났으면 미래 항을 **반드시 0으로** 처리.

### ② maxValue 보조 메서드
```java
private double maxValue(double[] values) { /* 6개 중 최댓값 반환 */ }
```
- `argMax`는 **위치**를 주고, `maxValue`는 **값**을 줍니다. 여기선 값이 필요.

### ③ 표 갱신 — "조금씩" 정답에 다가가기
```java
qTable[state][action] += LEARNING_RATE * (target - qTable[state][action]);
//                       α(0.1)         × (목표값  - 현재값)
```
- `(target - 현재값)` = **오차** (얼마나 틀렸나).
- 그 오차의 **10%(α=0.1)만큼만** 현재값을 목표 쪽으로 이동.
- 한 번에 확 바꾸지 않고 **조금씩** 옮기는 이유: 한 번의 운 좋은/나쁜 경험에 휘둘리지 않으려고.

```
현재값 ──(오차의 10%만큼)──▶ 목표값(target)
   2.0          +0.1×(5.0-2.0)=+0.3        2.3   (한 스텝 뒤)
```

이 `update`가 **매 스텝 6000칸 중 한 칸씩** 살짝살짝 고쳐지며, 수백 판이 쌓이면
표 전체가 똑똑해집니다.

## 4. 탐험 줄이기: `decayEpsilon`

```java
public void decayEpsilon() {
    epsilon = Math.max(EPSILON_MIN, epsilon * EPSILON_DECAY);  // 0.995배, 최소 0.01
}
```
- **에피소드(한 판)가 끝날 때마다** 호출 → epsilon이 조금씩 작아짐.
- `Math.max(0.01, ...)`로 **완전히 0이 되진 않게** 막음 (가끔은 계속 탐험해야 더 나은 길을 발견).

```
판이 진행될수록:  1.0 → 0.995 → 0.990 → ... → 0.01 (바닥)
              많이 탐험            거의 아는 대로
```

## 5. 전체 그림으로 다시 보기

```
   [매 스텝]
   selectAction(state)  ──▶ 행동 결정 (탐험 or 활용)
        │
        ▼  (행동 후 보상·다음상태 받음)
   update(s, a, r, s', done) ──▶ 표의 한 칸 갱신 (학습)

   [매 에피소드 끝]
   decayEpsilon()  ──▶ 탐험 비율 ↓
```

이 세 메서드(`selectAction`, `update`, `decayEpsilon`)가 Q-Learning의 전부입니다.
