## 1. 이 클래스의 일

파일: `src/main/java/com/mario/rl/network/SocketClient.java`

Java(클라이언트)가 Python(서버)과 대화하는 **전화기**입니다. 딱 두 가지 일을 합니다.

| 메서드 | 방향 | 하는 일 |
|--------|------|---------|
| `receiveGameState()` | Python → Java | 상태 JSON 한 줄 받아 `GameState`로 변환 |
| `sendAction(action)` | Java → Python | 행동을 `{"action": N}`으로 보냄 |

```java
public class SocketClient implements Closeable {
```
> `implements Closeable` → **try-with-resources**로 자동으로 소켓을 닫을 수 있게 합니다 (뒤에서 설명).

## 2. 연결, 그리고 재시도

[02장](02-전체구조와통신.md)에서 "Python을 먼저 켜야 한다"고 했죠. 하지만 사람이 둘을 동시에
켜다 보면 Java가 먼저 뜰 수도 있습니다. 그때 바로 죽지 않고 **기다렸다 다시 거는** 장치입니다.

```java
private static final int  MAX_RETRIES   = 10;
private static final long RETRY_DELAY_MS = 3000;   // 3초

private Socket connectWithRetry(String host, int port) ... {
    for (int attempt = 1; attempt <= MAX_RETRIES; attempt++) {
        try {
            Socket s = new Socket();
            s.connect(new InetSocketAddress(host, port));   // ① 연결 시도
            return s;                                        // ② 성공하면 반환
        } catch (IOException e) {
            Thread.sleep(RETRY_DELAY_MS);                    // ③ 실패하면 3초 쉬고
        }                                                    //    다시 반복
    }
    throw new IOException("...연결 실패...");                  // ④ 10번 다 실패하면 포기
}
```

- **①②** 연결되면 즉시 소켓을 돌려줌.
- **③** 거부되면(서버가 아직 안 켜짐) 3초 자고 재시도.
- **④** 10번(=30초) 다 실패하면 **예외를 던져** 솔직하게 포기.

```
Java 켜짐 ─연결❌─ 3초 ─연결❌─ 3초 ─ ... ─연결✅(Python이 켜짐!)
            1회         2회                  성공
```

## 3. 통로 만들기 (Reader / Writer)

```java
this.reader = new BufferedReader(
        new InputStreamReader(socket.getInputStream(),  StandardCharsets.UTF_8));
this.writer = new BufferedWriter(
        new OutputStreamWriter(socket.getOutputStream(), StandardCharsets.UTF_8));
```

- 소켓의 **날것 바이트 스트림**을, 글자를 다루기 쉬운 `Reader`/`Writer`로 감쌉니다.
- `StandardCharsets.UTF_8` → [02장](02-전체구조와통신.md)의 약속(UTF-8 인코딩)을 지킴.
- `BufferedReader.readLine()` 덕분에 **"줄 단위"로** 읽을 수 있습니다 (그래서 `\n`이 중요).

## 4. 받기: `receiveGameState`

```java
public GameState receiveGameState() throws IOException {
    String line = reader.readLine();              // ① 한 줄 읽기
    if (line == null) {                           // ② 끊겼는지 확인
        throw new IOException("서버 연결이 종료되었습니다 ...");
    }
    return gson.fromJson(line, GameState.class);  // ③ JSON → 객체
}
```

- **①** `readLine()`은 `\n`이 올 때까지 **한 메시지**를 읽어옵니다.
- **②** `null`이면 상대가 연결을 끊은 것 → 예외로 알림.
- **③** `gson.fromJson(...)`이 JSON 글자를 [04장](04-코드읽기-모델.md)의 `GameState` 객체로 **자동 변환**.

```
"{\"mario_x\":320,...}"  ──gson.fromJson──▶  GameState 객체(getMarioX()=320)
```

## 5. 보내기: `sendAction`

```java
public void sendAction(Action action) throws IOException {
    String json = "{\"action\": " + action.getValue() + "}";  // ① JSON 글자 만들기
    writer.write(json);
    writer.write("\n");                                        // ② 끝에 개행
    writer.flush();                                            // ③ 즉시 보내기
}
```

- **①** `action.getValue()`로 행동 번호를 꺼내 ([04장](04-코드읽기-모델.md)) `{"action": 2}` 같은 글자 생성.
- **②** **`\n`을 꼭 붙임** → 받는 Python이 "여기까지가 한 메시지"임을 알 수 있음.
- **③** `flush()` → 버퍼에 쌓아두지 말고 **지금 당장** 보냄.
  - 안 하면 Java는 메시지를 들고만 있고, Python은 영영 기다리는 **데드락**이 날 수 있음!

> ⚠️ `flush()`를 빠뜨리는 건 소켓 통신 초보가 가장 자주 겪는 버그입니다. 꼭 기억하세요.

## 6. 안전하게 닫기: `close` 와 try-with-resources

```java
@Override
public void close() throws IOException {
    socket.close();
}
```

`Closeable`을 구현했기 때문에, `Main`에서 이렇게 쓸 수 있습니다 (다음다음 장):

```java
try (SocketClient client = new SocketClient("localhost", 9999)) {
    ... 학습 ...
}   // ← 블록을 벗어나면 client.close()가 자동 호출됨 (예외가 나도!)
```

- **try-with-resources**: 소켓을 깜빡하고 안 닫는 실수를 원천 차단. 자원 누수 방지.
