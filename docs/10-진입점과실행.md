## 1. `Main`이 하는 일

파일: `src/main/java/com/mario/rl/Main.java`

`Main`은 로직이 거의 없습니다. **부품을 만들어 조립하고, 학습을 시작시키는** 게 전부입니다.

```java
public static void main(String[] args) {
    System.out.println("=== Mario RL (Q-Learning) 학습 시작 ===");

    try (SocketClient socketClient = new SocketClient(HOST, PORT)) {  // ① 연결
        QLearning qLearning = new QLearning();        // ② 부품 생성
        StateEncoder stateEncoder = new StateEncoder();
        Logger logger = new Logger();

        RLAgent agent = new RLAgent(qLearning, socketClient, stateEncoder, logger); // ③ 조립
        agent.train(MAX_EPISODES);                    // ④ 학습 시작

        System.out.println("=== 학습 종료 ===");
    } catch (IOException e) {                          // ⑤ 통신 오류 처리
        System.err.println("[Main] 통신 오류로 종료: " + e.getMessage());
    } catch (InterruptedException e) {
        Thread.currentThread().interrupt();
        System.err.println("[Main] 연결 대기 중 중단됨: " + e.getMessage());
    }
}
```

### 한 줄씩
- **①** `try (SocketClient ...)` → [08장](08-코드읽기-소켓통신.md)의 try-with-resources.
  Python에 연결(필요하면 재시도). 블록을 벗어나면 소켓 **자동 종료**.
- **②** 두뇌(`QLearning`), 인코더, 로거를 만듭니다.
- **③** 이들을 `RLAgent`에 **주입**해 조립 ([09장](09-코드읽기-에이전트.md)).
- **④** `train(500)` → 500 에피소드 학습 시작.
- **⑤** 통신이 끊기거나 연결 실패 시 **프로그램이 터지지 않고** 메시지를 남기고 정상 종료.

> 💡 `InterruptedException`에서 `Thread.currentThread().interrupt()`를 호출하는 건
> "중단 신호를 삼키지 말고 다시 표시해두는" 자바 관례입니다.

## 2. 상수로 모아둔 설정

```java
private static final String HOST = "localhost";
private static final int    PORT = 9999;
private static final int    MAX_EPISODES = 500;
```

- 바꿀 만한 값(주소·포트·학습량)을 **맨 위 상수로** 모아 한눈에 보고 쉽게 수정.
- 더 오래 학습시키고 싶으면 `MAX_EPISODES`만 키우면 됩니다.

## 3. 전체 조립도

지금까지 만든 모든 클래스가 `Main`을 통해 이렇게 연결됩니다.

```
                    ┌─────────── Main ───────────┐
                    │  (부품 생성 + 조립 + 시작)    │
                    └──────────────┬─────────────┘
                                   │ train(500)
                          ┌────────▼────────┐
                          │     RLAgent     │  ← 루프 지휘 (09장)
                          └───┬────┬────┬───┘
              selectAction/   │    │    │   receive/sendAction
              update          │    │    │
                  ┌───────────▼┐ ┌─▼────────┐ ┌▼──────────┐
                  │ QLearning  │ │StateEncoder│ │SocketClient│──▶ Python
                  │  (07장)    │ │  (05장)   │ │  (08장)   │
                  └───────────┘ └──────────┘ └───────────┘
                        ▲                          ▲
                     Logger(06장)            Action/GameState(04장)
```

## 4. 실제로 실행하기

> ⚠️ Python 게임 서버는 **아직 이 저장소에 없습니다**(추후 추가 예정).
> 그래서 지금은 Java만으로 "연결 재시도" 동작까지 확인할 수 있습니다.

### 최종 실행 순서 (Python 서버가 준비된 후)

```bash
# 터미널 1: Python 게임 서버 먼저
cd python/
pip install -r requirements.txt
python mario_env_server.py

# 터미널 2: Java 학습 클라이언트
./gradlew run
```

### 지금 (Python 없이) 확인할 수 있는 것

```bash
./gradlew run
```
→ 콘솔에 이런 로그가 반복되면 **정상**입니다 (서버가 없어 재시도 중):

```
=== Mario RL (Q-Learning) 학습 시작 ===
[SocketClient] 연결 실패 (1/10). 3000ms 후 재시도...
[SocketClient] 연결 실패 (2/10). 3000ms 후 재시도...
...
```
[08장](08-코드읽기-소켓통신.md)의 재시도 로직이 그대로 동작하는 모습입니다.

### Python까지 붙으면 보게 될 것

```
[Episode    1] Total Reward:    -42.0 | Max X:   240 | Epsilon: 0.995
[Episode    2] Total Reward:     15.3 | Max X:   410 | Epsilon: 0.990
...
[Episode  120] Total Reward:   1820.5 | Max X:  2400 | Epsilon: 0.548
```
→ `Total Reward`와 `Max X`가 **점점 커지면** 마리오가 학습으로 더 멀리 가는 중! ([06장](06-코드읽기-로거.md))
