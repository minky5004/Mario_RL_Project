# [DAY12] 다른 두뇌 — Monte Carlo (알고리즘 비교 ③)

> 🎯 처음으로 **부트스트랩을 버린** 두뇌 — 에피소드가 끝날 때까지 기다렸다가 실제 받은 보상으로 갱신한다.

**배경** · [DAY10~11] QL·SARSA·ESARSA는 본선 무승부 + 바닥선 위 분리, 견고한 차이는 timeout뿐. 셋 다 "다음 상태의 추정치"로 갱신한다(부트스트랩). MC는 그 추정을 안 쓴다.

*가설은 실험 전에 먼저 쓴다(예측→검증).*

---

## 공통 설정

DAY10~11과 동일. 두 테이블(108+1080) · α=0.1 · γ=0.99 · ε 1.0→×0.995→0.01 · 프레임 스킵 2 · 1500판 · 6행동 · 5시드.

---

## 🤔 왜 이 방향인가

TD는 추정에 추정을 쌓아 **편향** 가능하지만 매 스텝 신호가 와 **분산이 작고 빠르다**. MC는 정반대 — 실제 return G로 갱신하니 **편향 없음, 분산 큼**. 1-1은 큰 보상이 종료 시점에 몰려 있어(클리어 +1000·사망 −100), MC는 그 신호를 궤적 전체에 역방향으로 한 번에 칠한다.

## 변경
- `MonteCarlo extends TabularBrain` — 두 테이블·ε-greedy·저장/로드 재사용, **갱신 타이밍만** 변경:
  - `learn`은 궤적만 쌓고, `endEpisode`에서 역방향으로 `G ← r_t + γ·G`를 누적하며 `updateToward(target=G)`(TD와 같은 갱신식, α/2 분할).
  - **every-visit · constant-α.** `bootstrap` 미사용(호출 시 예외) — "bootstrap 한 줄만 다르다" 패턴을 처음 벗어난 두뇌.
- `-Dmario.algo=monte_carlo`. 6행동·1500판·시드 1~5.

## 가설
- **① 본선은 또 무승부** — 단 바닥선 위 분리는 돼야 진짜 학습([DAY10] 잣대).
- **② MC 고유 차이는 분산 축** — 시드 분산↑·초반 출렁임(ε 높은 초반엔 무작위 궤적의 G로만 배움).
- **③ timeout은 on/off-policy 성향과 무관**할 것.

- **본선에서 처음으로 밀렸다** — clear 4.8[0~12]은 TD 셋보다 분포째 낮고 후반 823도 TD(1173~1284) 아래. **챕터 최초의 "본선 무승부 깨짐".**
- **timeout 580 ≈ Random 588 = MC의 시그니처** — 거의 무학습과 같은 빈도로 끝을 못 낸다.
- **단 깃발엔 닿는다**(best 3024, 4/5) — 완전 실패는 아니다.
- **바닥선 분리도 애매** — seed3 후반 491 < Random 최대 667.
- dead_pit 177 = 멀리 못 가서 덜 빠진 것(부산물).

## 결론

- **① 기각** — 알고리즘만으로 본선 성적이 갈린 첫 사례. **② 적중** — 시그니처는 timeout 580: 부트스트랩을 버리니 전진 보상(+0.1×px)을 그때그때 전파 못 해 "끝내기"를 약하게 배움 → **sparse-reward 1-1에서 부트스트랩의 가치를 역설적으로 증명.**
- 챕터 메시지: TD 셋 = "무승부 + 바닥선 위" ↔ **MC = "본선 열세 + 바닥선에 가끔 닿음"** — 단 깃발엔 닿는 "약하게 학습하는 두뇌".
- 한 줄: **"부트스트랩을 버린 대가 = 끝을 못 냄(timeout Random급). 깃발엔 닿지만 본선에서 TD에 처음 밀린 두뇌."**
