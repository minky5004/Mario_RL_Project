# [DAY15] 흔적을 남기다 — SARSA(λ) 적격흔적 (세로 심화 ①)

> 🎯 **새 챕터 — 두뇌 하나씩 강화(세로 심화 2막).** 가로 비교(DAY10~14)로 7개 두뇌를 깔았으니, 이제 각 두뇌를 **교과서적 다음 버전으로 세로로 발전**시킨다. 첫 타자 = **SARSA → SARSA(λ)**, 적격흔적(eligibility trace).

**배경** · [DAY10] SARSA는 본선 무승부(견고한 차이는 timeout 97뿐), [DAY12] MC는 부트스트랩을 버려 약했다. 둘은 한 스펙트럼의 양 끝 — **1-step(신용 전파 한 칸씩) ↔ MC(판이 끝나야 전파)** — 이고 그 사이를 잇는 손잡이가 **λ**다.

*가설은 실험 전에 먼저 쓴다(예측→검증).*

---

## 공통 설정 (baseline과 고정)

DAY10~14와 동일, 알고리즘만 SARSA → SARSA(λ). baseline = [DAY10] SARSA(같은 시드 재사용).

| 항목 | 값 |
|---|---|
| 상태·테이블 | 두 테이블(108+1080), α=0.1 · γ=0.99 |
| epsilon | 1.0 → ×0.995/판 → 하한 0.01 |
| 프레임 스킵 · 에피소드 · 행동 | 2 · 1500 · **6개** |
| 시드 반복 | 5회 |
| **추가 손잡이** | **λ=0.9** (replacing trace), `-Dmario.lambda` |

---

## 🤔 왜 이 방향인가 — 그리고 새 자(尺)가 필요하다

**왜 적격흔적인가.** 1-step SARSA는 TD 오차를 직전 상태 하나에만 반영 — 깃발 +1000이 출발선까지 스미려면 느리다. 적격흔적은 **최근 밟은 상태들에 "책임 꼬리표"를 남겨 한 번의 오차를 과거로 한꺼번에 전파**한다. MC가 못 한 빠른 전파를, 부트스트랩은 유지한 채 한다.

**⚠️ 왜 새 지표인가.** SARSA도 이미 깃발을 뽑아, 최종 clear·거리는 본선 분산에 묻힐 공산이 크다(DAY9·10). 적격흔적의 진짜 주장은 "**더 빨리** 배운다" — 학습 속도를 재는 자를 새로 든다:

| 새 지표 | 정의 | 무엇을 잡나 |
|---|---|---|
| **첫-클리어 판수** | 처음 깃발에 닿은 에피소드(낮을수록 빠름, 못 하면 ∞) | 신용 전파 속도의 직접 증거 |
| **학습곡선 AUC** | 전체 1500판 평균 Max X | "얼마나 일찍부터 멀리 갔나" |
| **초반 300판 평균** | ep 1~300 평균 Max X | ε 높을 때의 조기 성능 |

기존 지표도 보고하되 **판정은 새 지표 우선.** (이 자가 이후 세로 심화의 기본.)

## 변경
- `SARSALambda extends SARSA` — 부트스트랩은 같으므로 상속, `learn`·`endEpisode`만 오버라이드.
  - 흔적 테이블 `eCommon`·`eLocal`(가치와 같은 모양). 매 스텝: δ 계산 → 현재 (s,a) 흔적 **1로(replacing)** → 활성 흔적 전체에 `Q += α/2·δ·e` 후 `e ← γλ·e`. 에피소드 끝 흔적 0.
  - replacing trace = 재방문 폭주 방지(Sutton 기본). 활성 목록으로 전체 스윕 회피(γλ=0.891이라 ~80스텝이면 소멸).
- `-Dmario.algo=sarsa_lambda` + `-Dmario.lambda`(기본 0.9). 6행동·1500판·시드 1~5.

## 가설
- **① 첫-클리어가 SARSA보다 빠름(1순위)** — 적격흔적의 핵심 주장.
- **② 본선 최종은 무승부** — TD끼리 분산에 묻힘(DAY9·10 재현)이 오히려 예측.
- **③ AUC·초반 300 위.** **④ timeout < SARSA(97)** — 흔적이 "끝내기" 경로를 빨리 강화.
- **⑤ 시드 분산은 여전히 클 것.**

![SARSA(λ) vs SARSA](images/day15-sarsa-lambda-vs-sarsa.png)

- **분포가 안 겹친다 — 분산 신기루가 아니다.** clear 최소 199 > SARSA 최대 60, 첫-클리어 최대 346 < SARSA 최소 824. DAY9~11에서 TD끼리 늘 겹치던 분산을 **적격흔적이 정면으로 뚫었다.**
- 학습곡선: ~250판까지 붙어 있다가 빨강(λ)만 급격히 갈라져 후반 ~2100(SARSA는 ~1200).
- **timeout 97→17 (1/6)** — on-policy "우물쭈물"이 거의 소멸.

## 결론

- **① 강적중** — 230 vs 866, 5/5 전 시드 클리어(SARSA는 seed3 미클리어).
- **② 기각(좋은 쪽)** — 최종값까지 분포째 압도. 효과가 분산을 넘었다 → **세로 심화 첫 완승.**
- **③ 적중 · ④ 강적중 · ⑤ 실질 기각**(std는 남지만 분포가 안 겹쳐 결론을 못 뒤집음).
- **왜 컸나** — sparse-reward 1-1이 정확히 원하던 처방: "부트스트랩 유지 + 신용은 흔적만큼 한꺼번에 뒤로"(1-step의 느림과 MC의 무모함 사이).
- 한 줄: **"적격흔적 한 축으로 SARSA를 분포째 압도 — 첫 깃발 3.8배 일찍(5/5)·클리어 12배·timeout 1/6. 세로 심화 첫 완승."**
