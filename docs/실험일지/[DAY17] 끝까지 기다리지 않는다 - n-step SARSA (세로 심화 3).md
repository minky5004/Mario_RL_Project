# [DAY17] 끝까지 기다리지 않는다 — n-step SARSA (세로 심화 ③)

> 🎯 **가장 약했던 학습기를 손본다.** [DAY15] λ 완승·[DAY16] Double-Q 후퇴가 가리킨 결론 — **강화의 방향이 진짜 병목(sparse-reward 신용 전파)과 맞아야 이득.** 그렇다면 그 병목에 정면으로 당한 [DAY12] Monte Carlo에, 버렸던 **부트스트랩을 도로 넣으면** 어떻게 되는가. 손잡이는 **n**이다.

**배경** · MC는 부트스트랩 없이 판이 끝나야 배웠다 → clear 4.8·후반 823·**timeout 580 ≈ Random 588**(끝을 못 냄). 전진 보상조차 즉시 전파 못 한 것 = 부트스트랩 가치의 역설적 증명. 이제 MC↔TD 스펙트럼을 n으로 직접 걸어본다.

*가설은 실험 전에 먼저 쓴다(예측→검증).*

## 🤔 왜 이 방향인가 — n은 MC와 TD를 잇는 유일한 손잡이

```
G = r_t + γ·r_{t+1} + … + γ^{n-1}·r_{t+n-1}  +  γ^n · Q(S_{t+n}, A_{t+n})
    └────── 실제로 받은 보상 n개 ──────┘        └── 부트스트랩(추정치) ──┘

n = 1        → 1-step SARSA   [DAY10]
n = 8        → 이번 실험
n = 에피소드  → Monte Carlo    [DAY12]
```

MC가 못 한 것(빠른 전파·끝내기)을 부트스트랩으로 되찾되, 실제 보상을 8칸 실어 신용 할당도 빠르게. **n=8**은 [DAY15] λ=0.9의 유효 horizon(≈10스텝)과 대응 — SARSA(λ)와 직접 견줄 자리.

**구현 검증(추측 말고 측정)**: 같은 (s,a,r,s',a') 시퀀스에서 **n=1 ≡ SARSA · n=∞ ≡ Monte Carlo**(Q테이블 최대 오차 0). 경계가 비트 단위로 같으니 중간값 n=8도 신뢰.

판정은 [DAY15] 새 지표(첫-클리어·AUC·초반 300) 우선 + 기존 지표.

## 변경
- `NStepSARSA extends SARSA` — 부트스트랩 규칙이 SARSA와 같으므로 상속, `learn`·`endEpisode`만 오버라이드([DAY15] 패턴).
  - **슬라이딩 창**: 최근 n스텝 큐, 창이 차면 가장 오래된 스텝을 `실제 보상 n개 + γⁿ·부트스트랩`으로 갱신하며 pop(n스텝 지연).
  - **에피소드 꼬리**: 남은 스텝은 MC처럼 역방향 실제 return으로 마감(= "n=∞면 MC"의 근거). γ 거듭제곱 캐시.
- `-Dmario.algo=nstep_sarsa` + `-Dmario.nstep`(기본 8). 6행동·1500판·시드 1~5.

## 가설
- **① 본선에서 MC를 분포째 이김(1순위)** — 부트스트랩 복원은 [DAY12]가 스스로 짚은 처방. 헤드룸이 커서 분산에 안 묻힌다.
- **② timeout 급락** — MC 시그니처(580)가 SARSA(λ)(17)~TD(43~97) 수준으로.
- **③ 첫-클리어가 이르고 5/5 클리어 가능.**
- **④ 단 SARSA(λ)엔 못 미침** — 흔적은 모든 과거에 지수 가중, n-step은 딱 n칸 + n스텝 지연.
- **⑤ 규칙 재검증** — 신용 전파 축이면 이긴다(다른 두뇌에서 한 번 더).

## 결론

- **① 강적중** — clear·AUC·후반거리 세 축 모두 다섯 시드 완전 분리.
- **② 가장 강하게 적중** — 580→59. "끝을 못 냄"이 부트스트랩 부재 탓임을 인과 확정([DAY12] 자기 진단이 처방까지 맞음).
- **③ 부분 적중**(5/5 달성, 평균 비교는 보류) · **④ 적중** — SARSA(λ)가 전 지표 위(clear 279·AUC 1627·후반 2079·timeout 17). 같은 horizon인데 흔적이 이기는 이유 = **모든 과거에 지수 가중 + 즉각 갱신** vs 8칸 + 8스텝 지연.
- **⑤ 재확인 — 세 번째 데이터점**: 신용 전파를 건드린 둘(λ·n-step)은 이겼고, 값의 편향을 건드린 하나(Double-Q)는 졌다.
- **부트스트랩의 값어치, 양방향 증명 완료** — [DAY12] 빼서 나빠짐(역설) + [DAY17] 넣어서 좋아짐(직접).
- 한 줄: **"MC에 부트스트랩 8칸을 되돌려 timeout 580→59·clear 5→206으로 부활 — 단 SARSA(λ)엔 못 미친다(흔적이 n칸 창보다 부드럽고 즉각적)."**
