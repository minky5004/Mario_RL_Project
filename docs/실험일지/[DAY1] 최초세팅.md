## 해석 (정직하게)

**① 학습은 사실상 실패 — 후반에 더 못 감.** Max X 이동평균이 초반(ep20~30) ~900 정점 후 하락(760→480), 조기사망 17→31. **epsilon이 낮아져 "배운 대로"(greedy) 움직일수록 더 일찍 죽었다.**

**② 보상 −340→−75 개선은 전진 덕이 아니다** — 초반 후퇴(−5) 남발이 줄었을 뿐. −75/MaxX≈290은 "걷다가 사망"의 서명(전진 +25 후 사망 −100).

**③ 원인 가설** — 상태 인코딩이 너무 거칠어(100px) 장애물 위치·점프 타이밍을 표현 못 함. raw 점들이 ~290/~700/~1130/~1400 가로줄로 뭉침 = 1-1의 고정 사망 지점들.

## 결론
- "오른쪽으로 가기"는 학습, **"장애물 통과"는 학습 못 함.** greedy가 무작위보다 못한 건 *상태 구분력 부족*의 신호.

## 심층 해석 — 원인 세 층

```
거친 100px 인코딩(ⓐ)       →  장애물을 "표현" 자체를 못 함
   ↓
전진 보상 +0.1/px 편향(ⓑ)  →  "오른쪽으로 걷기" 정책 고착
   ↓
epsilon 감쇠(ⓒ)            →  우연히 넘던 무작위 점프가 사라짐
   ↓
결과                        →  매 판 같은 지점 직행. Max X 760→480
```

**ⓐ 근본 — 상태 알리아싱.** `index = xZone*20 + enemy*2 + yZone` — x200~299 전체가 한 상태. "안전한 x200"과 "위험한 x290"이 같은 칸이라 정반대 경험이 한 칸에서 싸우고, 점프 *타이밍*은 어떤 단일 행동으로도 표현 불가. **표 기반 + 거친 인코딩의 구조적 천장 = 1순위 원인.**

**ⓑ 증폭 — 직진 함정.** 전진 보상은 즉시·항상 양수라 "오른쪽"이 점프보다 먼저 각인. 사망 −100은 마지막 한 행동에만 꽂히는데 전진 +는 여러 걸음에 쌓여, 위험 칸의 "오른쪽" 점수가 충분히 안 내려간다.

**ⓒ 방아쇠 — ε 감쇠.** 정점 ep20~30은 ε≈0.88(88% 랜덤)의 **행운**이었고, ep400~(ε≈0.08)엔 그 우연한 점프가 사라져 매 판 결정론적으로 같은 곳에 빠짐. "배운 대로 갈수록 일찍 죽는" 건 정책이 나빠서가 아니라 **그 상태로는 좋은 정책을 표현할 수 없어서** — 다시 ⓐ로 귀결.

**→ DAY2**: (1순위) 상태 세분화 — 위험 신호(거리)를 인코딩에 추가. 보상·ε은 별도 실험으로(한 번에 하나만).
