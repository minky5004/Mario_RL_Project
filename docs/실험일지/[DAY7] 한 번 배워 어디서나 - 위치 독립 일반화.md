# [DAY7] 한 번 배워 어디서나 — 위치 독립 일반화

> 🎯 굼바를 위치 독립으로 일반화한다.

**배경** · DAY6은 예산을 늘려 구덩이를 95% 넘었으나 새 병목 x1750~2000 적에서 20%에 막힘. **측정 = 관문별 통과율 제각각(첫 굼바 61 · 2차 76 · 구덩이 95 · x1800 20%) = 일반화 실패.** 범인은 상태의 `xZone` — 같은 "굼바 가까움"도 x290·x1800이 다른 칸이라 학습이 안 옮겨간다.

*가설은 실험 전에 먼저 쓴다(예측→검증).*

## 트라이 1 — 위치 빼기 (상태 1080 → 36)

### 🤔 왜 이 방향인가
점프할지 정할 때 필요한 건 "내가 몇 m 지점인가"가 아니라 **"눈앞에 뭐가 얼마나 가까운가"** — `enemyDist`·`pitDist`·`vyDir`가 이미 위치와 무관하게 알려준다. `xZone`은 일반화를 막는 방해물.

### 변경
- `StateEncoder`에서 `xZone` 제거. 상태 = `pitDist(3)×enemyDist(4)×vyDir(3)` = **36칸**.

### 가설
- x290·x1800의 "굼바 가까움"이 같은 칸 → 학습 전이 → x1800 통과율이 첫 굼바 수준(~61%)으로?
- **실패 분기**: 통과율이 *떨어지면* 위치로만 구별되는 상충 구간 존재(perceptual aliasing) → 트라이2(두 테이블).

### 결과 — 일반화는 대성공, 그런데 후반이 진동한다

![DAY7 트라이1 학습 그래프](images/day7-try1-graph.png)

| 지표 | DAY6 (1080칸) | **트라이1 (36칸)** | |
|---|---|---|---|
| **clear** | 0 | **3** 🏁 | ▲▲ |
| best Max X | 2477 | **3161 (깃발)** | ▲ |
| x1800 통과율 | 20% | **59%** | ▲▲ |
| 평균 Max X | 795 | 734 | ▼ |
| timeout | 27 | **132** | ▲(나쁨) |

- **① 일반화가 깃발을 뚫었다** — x1800 20→59%, **7일 만의 첫 클리어 3회**(ep295 첫 클리어 = 36칸이라 학습도 빠름).
- **② ε이 굳은 뒤 롤러코스터**: 100판 평균이 955→467→679→912→411→665로 **붕괴↔회복 반복**(timeout 0↔44). 붕괴 구간엔 첫 굼바조차 못 넘음. 이 진동이 평균을 갉아 clear 3인데 평균은 DAY6보다 낮다.

### 결론
- **일반화 가설 입증**(안대 부작용 없음 — 1-1엔 위치로만 구별되는 상충 굼바가 없다).
- **새 부작용 = 36칸 진동**: 한 칸의 Q값이 흔들리면 그 칸을 공유하는 많은 상황이 한꺼번에 무너지고, ε≈0이라 탐험으로 못 빠져나옴 — **칸 공유의 양날.**
- → 트라이2의 필요성이 데이터로 드러남: 일반화는 얻되 진동 칸을 `Q_위치`로 분리·안정화.

## 트라이 2 — 두 테이블 합치기 (공통 + 위치)

> 사용자 발안 — coarse/tile coding.

### 변경
- Q-Table을 **둘**로: `Q_공통[36]`(위치 무시) + `Q_위치[1080]`(위치 포함). 선택·갱신 모두 **합산**(`Q = qCommon + qLocal`), TD 오차는 **양쪽에 α/2씩**(실효 학습률 발산 방지).

### 가설
- `Q_공통` = 일반화("굼바=점프"를 빠르게), `Q_위치` = 특정 지점 예외 덧칠 → **일반화 유지 + 진동 안정화** 둘 다?

### 결과 — 두 테이블이 트라이1을 압도한다

![DAY7 트라이2 학습 그래프](images/day7-try2-graph.png)

| 지표 | 트라이1 (36칸) | **트라이2 (두 테이블)** | |
|---|---|---|---|
| **CLEAR** | 3 | **17** 🏁 | 5.7배 |
| 평균 Max X | 734 | **1098** | +50% |
| **timeout** | 132 | **46** | 1/3 |
| 구덩이 통과율 | 42% | **78%** | ▲▲ |
| x1800 | 59% (22도달) | 38% (**320도달**) | 도달 14배 |

- **진동이 잡히고 후반이 우상향**: ep901~ 평균 1284→1559→…→**1844**(timeout 7→4→0), 붕괴 없음.
- @500판엔 느렸으나(1080칸 재등장 + α/2) 600판 이후 전 지표 추월. x1800은 통과율만 낮아 보이나 도달이 14배라 절대 통과수 압도.

### 결론
- **가설 완전 입증 — 두 테이블이 답.** `Q_공통`이 clear 3→17, `Q_위치`가 timeout 132→46·붕괴→우상향. "빠른 일반화 + 안정성" 둘 다.
- **사용자 발안(tile/coarse coding)의 승리** — DQN·함수근사로 가는 정석 기법을 테이블에 한 겹으로.

## DAY7 종합 — 위치를 "빼고" → "되살려 합치다"

| 트라이 | 상태 | clear | 평균 | timeout | 핵심 |
|---|---|---|---|---|---|
| **1** | 위치 제거 (36) | 3 | 734 | 132 | 일반화로 **첫 클리어**, 단 진동 |
| **2** | 공통 36 + 위치 1080 | **17** | **1098** | **46** | 일반화 + 안정화 = **압승** |

- **관통 교훈**: 같은 정보(위치)도 **"넣느냐 빼느냐"가 아니라 "어떻게 합치느냐"** — 빼면 일반화하나 불안정, 넣으면 암기, 합치면 둘 다.
- **현재 위치**: 1500판 중 17회 클리어, 후반 평균 1844 우상향. 다음 후보: 행동 공간(긴 점프)·예산·1-1 졸업.
