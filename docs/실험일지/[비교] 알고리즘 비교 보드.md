# [비교] 알고리즘 비교 보드

> 🏁 **같은 마리오(1-1), 다른 두뇌.** 소켓 뒤 Python(게임·보상·측정)은 *누가 행동을 정하는지* 모른다. Java 두뇌만 갈아끼우면(`-Dmario.algo`) **완전히 같은 환경**에서 알고리즘들을 줄세울 수 있다. 이 파일은 그 비교군을 **한 표에 모아 두는 보드**다 — 새 두뇌를 붙일 때마다 한 줄씩 쌓는다.

알고리즘별 자세한 과정·가설·해석은 각 DAY 일지에, **결론용 숫자(5시드 분포)는 여기**.

---

## 고정 설정 (모든 비교군 공통)

| 항목 | 값 |
|---|---|
| 환경 | `gym-super-mario-bros` 1-1 고정, frame skip 2 |
| 상태·테이블 | 두 테이블(공통 108 + 위치 1080), α=0.1 · γ=0.99 |
| epsilon | 1.0 → ×0.995/판 → 하한 0.01 |
| 행동 | **6개(긴 점프 OFF)** — DAY9에서 효과 없음 확인, 알고리즘 변수만 격리 |
| 예산 | 1500판 |
| 반복 | **시드 1~5 (5회)** — 결론은 분포로만 |

> ⚠️ **읽는 법(DAY8·9 교훈)**: 단일 실행으론 트라이를 못 가린다(실행 분산 ≫ 알고리즘 차이). 모든 칸은 **5시드 분포(mean ± std [min~max])**. 두 비교군의 범위가 겹치면 "차이 없음"으로 읽는다.

## 한 줄 요약 (지금까지)

- **세 TD 학습기(QL·SARSA·Expected SARSA) = 본선 무승부.** clear·거리·best 분포가 완전히 겹친다(시드 영향 ≫ 알고리즘, DAY9 재현). 셋 다 seed4가 폭발하는 등 시드가 성능을 좌우.
- **세 TD는 Random을 깨끗이 이긴다.** Random은 깃발 0·거리 654±17인데, 세 TD 거리 최솟값(907·830·707) > Random 최댓값(667) — 학습군과 바닥선이 안 겹친다. → 클리어·거리 모두 *진짜 학습*(분산 아님).
- **Monte Carlo는 처음으로 다른 군.** 본선에서 TD에 *분포째* 밀리고(clear 4.8 ≪ TD, 후반거리 823 < TD), timeout이 **Random급(580 ≈ 588)** = 끝을 못 냄. 바닥선 분리도 애매(seed3 후반 491 < Random 667). 단 깃발엔 닿음(best 3024) = "약하게 학습". **부트스트랩을 버린 대가**.
- **GA는 바닥선 *아래*로 처음 떨어졌다.** 후반거리 603 < Random 654 · best 1632 < Random 2109 · 깃발 0 · timeout 1122(Random의 2배). [DAY10] 잣대("학습기는 바닥선보단 나아야")를 **처음 통과 못 한 학습기**. 진화 자체가 나빠서가 아니라 **8천 파라미터 × 30×50 예산 × timeout이 덜 아픈 적합도 × 스텝 신용할당 없음**의 합작.
- **ES는 GA보다도 아래 — 전 지표 최하위이자 *유일하게 퇴보*하는 두뇌.** 후반거리 64·best 905·timeout 1389(챕터 최고) 모두 꼴찌. 구간별 평균이 `~155(초반)→~64(후반)`로 **시간이 갈수록 나빠진다**(그래프에서 ES만 우하향). 단일 부모가 "안전 timeout(−50 > 사망 −100)" 분지로 빨려들면 모집단 다양성으로 버틸 GA와 달리 통째로 collapse. **σ는 동결을 늦출 뿐(0.1=즉시·0.3=느리게), 범인은 보상 지형.** → **GA·ES 두 점으로 "이 환경에선 진화 패밀리 자체가 약함"이 확정**(GA 구현만의 탓이 아님), 그중 부모 하나인 ES가 가장 취약.
- **TD 안 견고한 차이는 timeout.** SARSA 97(on-policy 우물쭈물) → Expected SARSA 63(정책 기댓값으로 완화) → QL 43. on/off-policy 성향이 timeout 축에서만 드러난다. (MC 580·GA 1122·ES 1389는 이 축의 극단.)
- **읽는 법**: "누가 낫나"(TD끼린 분산에 묻힘)가 아니라 **"각 두뇌가 바닥선 *기준* 어디냐"** — 줄세우면 TD 셋(위) > MC(사이, 깃발엔 닿음) > Random(바닥) > GA(그 아래) > **ES(맨 아래·유일한 우하향)**.

## 새 두뇌 추가하는 법 (재현 레시피)

1. `Brain` 구현(또는 `TabularBrain` 상속, `bootstrap`만 정의) + `Main.createBrain`·`-Dmario.algo`에 등록.
2. **6행동·1500판·시드 1~5**로 baseline과 **같은 조건** 실행(시드 병렬 = docker 포트 9991~9995 / java `-Dmario.seed`·`-Dmario.port`).
3. 각 시드 Python `[Ep N] status=…maxX=…` 로그 집계 → 이 표에 **분포(mean ± std [min~max])** 한 줄 추가.
4. 자세한 가설·과정은 해당 DAY 일지에, 결론 숫자만 여기.
