# [비교] 알고리즘 비교 보드

> 🏁 **같은 마리오(1-1), 다른 두뇌.** 소켓 뒤 Python(게임·보상·측정)은 *누가 행동을 정하는지* 모른다. Java 두뇌만 갈아끼우면(`-Dmario.algo`) **완전히 같은 환경**에서 알고리즘들을 줄세울 수 있다. 이 파일은 그 비교군을 **한 표에 모아 두는 보드**다 — 새 두뇌를 붙일 때마다 한 줄씩 쌓는다.

알고리즘별 자세한 과정·가설·해석은 각 DAY 일지에, **결론용 숫자(5시드 분포)는 여기**.

---

## 고정 설정 (모든 비교군 공통)

| 항목 | 값 |
|---|---|
| 환경 | `gym-super-mario-bros` 1-1 고정, frame skip 2 |
| 상태·테이블 | 두 테이블(공통 108 + 위치 1080), α=0.1 · γ=0.99 |
| epsilon | 1.0 → ×0.995/판 → 하한 0.01 |
| 행동 | **6개(긴 점프 OFF)** — DAY9에서 효과 없음 확인, 알고리즘 변수만 격리 |
| 예산 | 1500판 |
| 반복 | **시드 1~5 (5회)** — 결론은 분포로만 |

> ⚠️ **읽는 법(DAY8·9 교훈)**: 단일 실행으론 트라이를 못 가린다(실행 분산 ≫ 알고리즘 차이). 모든 칸은 **5시드 분포(mean ± std [min~max])**. 두 비교군의 범위가 겹치면 "차이 없음"으로 읽는다.

## 한 줄 요약 (지금까지)

- **🚀 최상위권은 이제 "흔적 듀오" — SARSA(λ) + Watkins Q(λ) (DAY15·DAY20 세로 심화).** SARSA(λ)(clear 279±56·후반 2079·timeout 17)가 여전히 서열 1이지만, [DAY20] Q(λ)(clear 225±38·후반 2005·timeout 17)가 **본선 분포를 겹치며** 바로 옆에 섰다 — on/off-policy 양쪽 모두 적격흔적이 정답. 둘의 뚜렷한 차이는 **초반뿐**(첫 깃발 230 vs 470 = Watkins cut이 ε 높은 초반 흔적을 자르는 비용) → [DAY20].
- **🥈 n-step SARSA(n=8)가 2위 — 세로 심화로 부활한 Monte Carlo.** 이 자리는 원래 MC(clear 4.8·후반거리 823·timeout 580 = Random급 "끝을 못 냄")였다. **버렸던 부트스트랩을 8칸만 되돌리자** clear 206·후반거리 1745·timeout 59로 뛰어올라 **TD 3형제(QL·Expected·plain SARSA)를 모두 넘어섰다.** 다만 SARSA(λ)에는 전 지표에서 못 미친다(흔적이 n칸 창보다 부드럽고 즉각적) → [DAY17].
- **plain TD로 남은 건 Expected SARSA 하나.** 옛 "TD 3형제 본선 무승부"(QL·SARSA·ESARSA 분포 겹침, 시드 영향 ≫ 알고리즘) 구도의 마지막 대표 — QL·SARSA 자리는 세로 심화(λ)가 가져갔다. **흔적 듀오·n-step은 그 무승부를 깨고 위로 빠져나온 것** = 세로 심화가 "가로 비교에서 묻히던 차이"를 실제로 만들어냄.
- **TD 계열은 Random을 깨끗이 이긴다.** Random은 깃발 0·거리 654±17인데, TD 거리 최솟값(SARSA(λ) 1767·Q(λ) 1792·n-step 1538·Expected 707) > Random 최댓값(667) — 학습군과 바닥선이 안 겹친다. → 클리어·거리 모두 *진짜 학습*(분산 아님).
- **부트스트랩의 값어치가 양방향으로 증명됐다.** [DAY12]는 그걸 **빼서**(MC) 본선 첫 열세를 봤고, [DAY17]은 **도로 넣어**(n-step) 2위로 복귀시켰다. sparse-reward 1-1에서 "추정치로 미래를 잇는 것"이 얼마나 큰지 두 방향의 실험이 같은 답을 낸다.
- **GA는 바닥선 아래로 떨어졌었지만, GA v2가 되찾아왔다 (DAY13 → DAY18).** [DAY13] GA는 후반거리 603 < Random 654 · 깃발 0 · timeout 1122로 **[DAY10] 잣대("학습기는 바닥선보단 나아야")를 통과 못 한 유일한 학습기**였다. 그 실패를 "진화의 본질"이 아니라 **구현 조합**(결정론 정책 · 8천 파라미터 · timeout이 덜 아픈 적합도)으로 진단했고, [DAY18]에서 셋을 고치자(**softmax · 공통표만(756) · 적합도=maxX**) 후반거리 **791**·timeout **292**·best **3161**로 **Random을 분포째 넘고 깃발까지 들었다**(2/5 시드). **진단서가 맞았다.**
- **다만 고쳐도 TD 근처엔 못 온다.** GA v2 clear 0.8 · 후반거리 791 vs TD 1268~2079. 진화는 판 전체를 **스칼라 하나(적합도)**로 요약해 *어느 행동이 좋았는지*에 대한 신용 할당이 없다. 게다가 softmax(확률 정책)라 **적합도가 1판 표본 = 노이즈**여서, 깃발을 든 개체를 엘리트로 보존해도 재현되지 않는다(seed3: gen19 best 3161 → gen20 best 1425 = *실력이 아니라 운을 보존*). → **진화의 천장은 신용 할당의 부재.**
- **ES는 여전히 전 지표 최하위이자 *유일하게 퇴보*하는 두뇌.** 후반거리 64·best 905·timeout 1389(챕터 최고) 모두 꼴찌. 구간별 평균이 `~155(초반)→~64(후반)`로 **시간이 갈수록 나빠진다**(그래프에서 ES만 우하향). 단일 부모가 "안전 timeout(−50 > 사망 −100)" 분지로 빨려들면 모집단 다양성으로 버틸 GA와 달리 통째로 collapse. **σ는 동결을 늦출 뿐(0.1=즉시·0.3=느리게), 범인은 보상 지형.** → [DAY18]이 **GA에 대해서는** "진화 패밀리 자체가 약한 게 아니라 구현 조합 탓"을 입증했으므로, **ES도 같은 처방(적합도=maxX 등)으로 되살아날 가능성이 열렸다** — 아직 안 해본 실험이다.
- **timeout 축 = "끝을 낼 줄 아는가".** 흔적 듀오 **17**(SARSA(λ) 17±3 · Q(λ) 17±4, 최저 — 흔적이 "끝내기"를 강화) < n-step 59 < Expected SARSA 63 (교체 전 대표: QL 43 · plain SARSA 97, DAY10 baseline). **부트스트랩을 쓰는 두뇌는 전부 100 아래**인데, 안 쓰는 MC는 580(≈Random 588)이었다 — 이 축이 부트스트랩 유무를 가장 선명하게 가른다. (GA 1122·ES 1389는 극단.)
- **읽는 법**: 바닥선(Random) 기준 줄세우면 **흔적 듀오(SARSA(λ) ≳ Watkins Q(λ), 본선 겹침) > n-step SARSA > Expected SARSA > GA v2 > Random(바닥) > ES(맨 아래·유일한 우하향)**. **세로 심화를 거친 넷(SARSA(λ)·n-step·GA v2·Q(λ))은 모두 자기 baseline을 분포째 넘었다.** TD 쪽에서 이긴 셋이 손댄 축은 전부 **신용 전파**였고(값의 편향을 손댄 [DAY16] Double-Q만 후퇴 = 신용 전파 축 3승 0패), 진화 쪽에서 이긴 GA v2가 손댄 축은 **적합도가 가리키는 방향 + 막힘 탈출**이었다. **교훈은 하나 — 강화의 방향이 그 두뇌의 실제 병목과 맞아야 이득이 난다.** (TD의 병목 = "드문 보상을 얼마나 빨리 뒤로 보내느냐", 진화의 병목 = "적합도가 옳은 걸 가리키느냐".)

## 새 두뇌 추가하는 법 (재현 레시피)

1. `Brain` 구현(또는 `TabularBrain` 상속, `bootstrap`만 정의) + `Main.createBrain`·`-Dmario.algo`에 등록.
2. **6행동·1500판·시드 1~5**로 baseline과 **같은 조건** 실행(시드 병렬 = docker 포트 9991~9995 / java `-Dmario.seed`·`-Dmario.port`).
3. 각 시드 Python `[Ep N] status=…maxX=…` 로그 집계 → 이 표에 **분포(mean ± std [min~max])** 한 줄 추가.
4. 자세한 가설·과정은 해당 DAY 일지에, 결론 숫자만 여기.
