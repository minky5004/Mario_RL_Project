# 실험일지 v0 — 최초 세팅 (Baseline)

> 이 폴더(`docs/실험일지/`)는 **모델을 조금씩 개선하며 각 시도를 기록**하는 연구 노트다.
> 이 문서는 그 **기준점(baseline)** — 앞으로의 모든 실험은 이 v0과 비교한다.

작성일: 2026-06-18

---

## 0. 측정 지표 (무엇으로 "좋아졌다"를 판단하나)

| 지표 | 의미 | 좋아지는 방향 |
|------|------|---------------|
| **Max X (추세)** | 한 판에서 가장 멀리 간 x좌표 | 에피소드가 갈수록 **우상향** 📈 |
| **Total Reward (추세)** | 한 판 보상 총합 | 점점 **덜 음수 → 양수** |
| **클리어 도달 여부** | 깃발(x≈3000) 도달 | 후반에 가끔이라도 등장 |
| **수렴 속도** | 학습이 보이기까지 걸린 에피소드/시간 | 적을수록 좋음 |

> ⚠️ 한두 판의 값이 아니라 **수십~수백 판의 추세**로 판단한다 (무작위 변동이 크기 때문).

## 1. 초기 세팅 상세

### 알고리즘 / 하이퍼파라미터 (`QLearning.java`)
| 항목 | 값 |
|---|---|
| 알고리즘 | 테이블 Q-Learning (가치 기반, off-policy) |
| Q-Table | `double[1000][6]` (0 초기화) |
| 학습률 α | 0.1 |
| 할인율 γ | 0.99 |
| epsilon | 1.0 시작 |
| epsilon 감쇠 | ×0.995 / 에피소드 |
| epsilon 하한 | 0.01 |
| 에피소드 수 | 500 (`Main.java`) |

### 상태 인코딩 (`StateEncoder.java`)
- X좌표: 100px씩 **30구간**
- 적 유무: 0/1
- 높이: `y<160` 0/1
- → 공식상 최대 인덱스 583, **실제 사용 상태 ≈ 120개**

### 득점(보상) 기준 (`mario_env_server.py` / [03장](../03-보상설계.md))
| 상황 | 점수 |
|---|---|
| 오른쪽 이동 | +(이동 px × 0.1) |
| 왼쪽 이동(후퇴) | −5 (고정) |
| 제자리 | 0 |
| 사망 | −100 |
| 시간 초과 | −50 |
| 클리어 | +1000 |

### 환경
- 게임: `SuperMarioBros-1-1-v0` (1-1 고정)
- 프레임 스킵: **없음** (행동 1개 = 1프레임)
- 실행: Docker(python:3.10), gym 0.25.2 / nes-py 8.2.1
- 행동 6개: NOOP / RIGHT / RIGHT_JUMP / JUMP / LEFT / RIGHT_RUN_JUMP

## 2. 관찰 결과 (초기 16판 실측)

```
[Episode  1] Total Reward:   -99.6 | Max X: 290 | Epsilon: 0.995
[Episode  2] Total Reward: -1275.4 | Max X: 723 | Epsilon: 0.990
[Episode  4] Total Reward:   -79.1 | Max X: 301 | Epsilon: 0.980
[Episode  7] Total Reward:  -757.0 | Max X: 723 | Epsilon: 0.966
[Episode 13] Total Reward:  -179.7 | Max X: 666 | Epsilon: 0.937
[Episode 16] Total Reward: -1268.6 | Max X: 596 | Epsilon: 0.923
```

- **Max X**: 290~300 ↔ 595~723 두 부류를 **무작위로 진동** (우상향 추세 없음)
- **Total Reward**: −75 ~ −1350 진동
- **속도**: 16판 ≈ 2분 49초 → **한 판 ~10초**
- **epsilon**: 16판 만에 0.995→0.923 (아직 92% 무작위)

---

## 3. 해석 / 한계

- 지금 음수·진동은 **학습 실패가 아니라** 아직 **탐험(무작위) 구간**이기 때문. (epsilon이 높음)
- **느린 수렴**: `0.995^n=0.2` → 약 320판(~55분) 필요. 학습이 눈에 보이려면 한참 걸림.
- **보상 비대칭**: 전진은 +0.x씩, 후퇴는 매번 −5(고정) → 무작위 구간에서 Total Reward가 크게 음수.
- **표 + 거친 인코딩**(~120 상태): 1-1 완전 클리어는 어려울 수 있으나 **Max X 우상향**은 기대 가능.
